Project


Exploring Kenya’s Debt Vulnerabilities: The Impact on Foreign Exchange Reserves


Aim of the Project


Kenya’s public debt has increased exponentially over the last decade with the Medium Term Debt Sustainability Analysis for 2024 estimating it at USD 73.1 billion in nominal terms (70.8% of GDP). Of this amount, external debt is USD 38.8 billion which means that more than half of the country’s debt is denominated in foreign currency. This raises concerns on the ability of the country’s forex reserves to meet the debt obligations, as and when they fall due especially given the very real exposure to exchange rate risk as witnessed earlier in 2024 when significant loss in value of the shilling significantly increased the external debt stock. In June 2024, a USD 2 billion Eurobond maturity almost resulted in a default, but for a last minute intervention by the IMF as well as the issue of an international bond, which helped avert a looming debt default.

The project assesses Kenya’s ability to withstand external economic shocks by exploring the interplay between foreign exchange reserves and external debt accumulation, external debt service and foreign exchange earnings/sources.

Data


I used data that was batch downloaded from the World Bank website using the World Bank API (coding challenge 6). This addresses automation/replication. I downloaded nine different JSON files using a loop. These were saved to my GitHub account.

The files were in JSON format and I encountered a challenge as I couldn’t figure out how to use data in the JSON format to create the charts or how to convert them to the more usable CSV format. In the end, I used a JSON to CSV converter that I found online (konklone.io) to convert the data to CSV. I then manually created a CSV file, dropping missing values and only using data from the years with full data available.

I used python (pandas) to combine all the batch downloaded data into a combined data frame. Thereafter, I reshaped the data using python (pandas) to remove scientific notation and to convert from wide form to long form. However, I noted that some charts required wide form data for them to run effectively, so I saved different files of the same data in different formats depending on the needs of the chart. As a result, the charts use data from different CSV files.

Conclusion


While Kenya’s external debt increased rapidly in the past decade, foreign exchange reserves appear to be declining since 2023. This can be attributed to an increase in debt service obligations as shown in chart 2 and 5. Debt service as a percentage of exports has also increased significantly which eats into forex reserves and has left the country exposed to external economic shocks.

Over the last five years, forex reserve accumulation has mostly been driven by a substantial increase in personal remittances, and – as from 2021 – an increase in IMF credit when the Fund approved a loan to Kenya under the EFF/ECF facility to support its Balance of Payments. Though remittances are a good lifeline that has supported forex reserves over the years, it can be risky to the economy if they dry up. It would be more beneficial for the country to diversify and focus on increasing export earnings which will also drive up economic growth in addition to enhancing resilience to external economic shocks. Export earnings have not increased much over the last decade.

Notably, despite rapid accumulation of debt to enhance economic performance, debt accumulation doesn’t appear to have enhanced economic growth.
